# 第四轮:N6 —— 离线诊断找到的根因(2026-07-30 14:00)

第三轮训练期间做了两项离线分析(`analyze_surrogate.py`,纯 CPU),结论推翻了我原先"上自适应信赖域"的建议。

## 诊断 1:CPO 代理目标的**量级在任何步长下都不可用**

定义 ρ = 实际代价下降 / 代理预测的代价下降,其中实际下降用下一次**新采样**的 `cost_before` 度量。

| run | mode 分布 | 每步预测下降(中位) | 逐步 ρ 中位 | 窗口 ρ(W=20)中位 | 实测/宣称的步后代价 |
|---|---|---|---|---|---|
| E1(教科书分支,发散) | 765 cr*/235 r | 112.5 | −0.001 | −0.003 | 3.45× |
| E2(教科书+无功,发散) | 774 cr*/226 r | 75.2 | −0.001 | −0.001 | 3.02× |
| retry1(保守分支) | 875 cost_recovery | 30.6 | +0.002 | −0.000 | 4.39× |
| N1(+无功) | 840 cost_recovery | 21.9 | +0.001 | +0.000 | 2.85× |
| N3(+紧预算) | 930 cost_recovery | 28.3 | +0.003 | +0.000 | 10.09× |

关键点:**ρ≈0 在全部五个 run 里都成立,包括成功的那三个**;而且按 `kl_after` 四分位分组后 ρ **不随步长恶化**(四组中位数都在 ±0.02 内)。retry1 的 `cost_before` 1000 步从 55.9 降到 4.0,即真实下降约 0.05/step,而代理每步宣称 30——**乐观约 600 倍,且与步长无关**。

`cost_after` 是在候选参数上**真实重算**代理目标(`shared_system_macpo.py:154`),不是线性外推。所以这不是线性化误差,而是**在当前 batch 上靠重要性比值把代理压下去、对新采样毫无迁移**。

**推论(重要,且否掉了一个方案)**:任何基于 ρ 的自适应信赖域都救不回教科书分支——代理量级在所有步长上都无信息,不存在"步子小一点就可信"的区间。第一轮的经验结论由此升级为机理结论:**约束是稀有事件 hinge 且跨 episode 方差极大时,CPO 的可行性分支必须放弃,改为无条件恢复**。这可以作为独立的负面结果发表。

## 诊断 2:根因在**成本 critic 严重欠拟合**

| run | cost_before(末50) | critic RMSE(末50) | RMSE/信号 |
|---|---|---|---|
| retry1 | 4.02 | 4.46 | **111%** |
| N1 | 1.65 | 1.63 | **99%** |
| E1 | 195.8 | 110.6 | 56%(发散) |

成本 critic 的样本外误差与成本值本身同量级 → 成本优势几乎全是噪声 → 代理量级无信息(诊断 1),而策略仍能改进,靠的是上千步平均出的那一点系统成分。

直接原因:**critic 每个 update 只做 1 步 Adam,无 epoch、无 minibatch**(`safe_gru_trainer.py`,标准 MAPPO 是 4–15 epoch)。1000 updates 一共只有 1000 步梯度。

## N6 `v6q_nocomm_gru_macpo_criticfit` → `n6_criticfit`
唯一变量:`critic_epochs=8`(其余与 N1 完全相同,预算 raw 0.02,无功 1200 kVA)。
**实现注意**:`optax` 调度按 `apply_gradients` 次数推进,直接加 epoch 会让 critic 学习率提前 8 倍衰减到 0;因此 critic 用了单独的调度,`transition_steps` 乘以 `critic_epochs`,使"学习率 vs update 序号"曲线不变。`critic_epochs` 默认 1 且**只在 spec 显式声明时才写进 trainer config**,已用打补丁前后的 `build_gru_config` 逐字节对比验证 **22 个既有变体的 config 完全未变**(所以既有 checkpoint 指纹不受影响)。
**判据**:
- 若样本外 `cost_critic_loss` 明显低于 N1 同 update 且安全日 >18/28 → 成本信号只是欠拟合,critic 拟合是主线。
- 若 in-sample 降了但样本外与安全日不动 → 残差在当前观测下不可约,直接支持下一步做**电气前瞻观测**(v6 目前没有任何电气前瞻,`h2_day_ahead_forecast_enable` 只前瞻热负荷且 v6 未开)。
两种结果都有信息量。
**已知风险**:`clip_by_global_norm(5.0)` 可能让 8 步的收益很小(u24 时 8 步只把 in-sample loss 从 1614 降到 1603)。因此巡检要盯 N6 与 N1 在**同一 update** 上的样本外 `cost_critic_loss` 对比;若到 u200 仍无明显分离,说明干预强度不足,应记录并在下一轮改用更多 epoch 或更高 critic 学习率,而不是判定假设为假。

## 软裕度代价:评估侧障碍已排除(07-30 19:40,第六轮训练期间完成)

第五轮把「除 day 24 外全部剩余失败都是均值达标、最差 seed 越限」定为主要瓶颈,对应的候选方案是**软裕度代价**:训练时把 hinge 拐点内移到 0.96/1.04,评估仍在真实带 0.95/1.05 上判定,让策略有动机留裕度而不是贴着边界收敛。

现已排除,做了两件事:

1. **给 `scripts/evaluate_env_v6_by_day.py` 加了 `--env-override KEY=VALUE`**(可重复)。在 run 自身的 `env_overrides` 之上生效,值按 JSON 解析(`0.95`→float、`true`→bool、`[1,2]`→list,失败则按字符串)。软裕度变体的评估命令因此是:

   --env-override power_flow_vmin_pu=0.95 --env-override power_flow_vmax_pu=1.05

## 第十四轮(2026-08-02):氢价单位改正 —— 30 元/kWh_H2 → 30 元/kg

### 动机

rollout 解剖(REPORT.md 附录)发现 `lambda_h2_buy = 30.0` 的单位是**元/kWh_H2**,
而 `LHV_H2 = 33.33 kWh/kg`,所以现行氢价等于 **1000 元/kg**,比真实灰氢(20–40 元/kg)
高约 33 倍。这一个数同时造成两个失真:

1. `_terminal_asset_values()` 在 `terminal_h2_value_yuan_per_kwh = 0.0` 时回落到
   `lambda_h2_buy`,于是期末在罐氢按 30 元/kWh_H2 计入信用,而本策略的制氢边际成本上界
   只有 0.602 元/kWh_H2 —— **50 倍套利**,直接导致电解槽全天顶格、不看电价。
2. 期末信用恰等于外部买价,使「囤氢」与「送给缺氢邻居」等价,而运输有途损,于是囤积严格
   占优,内部市场不出清(A0/A1 按 3 元甩卖同时 A3 按 30 元外购)。

### 预注册判定条件

**主判据(行为学,定性):** 电解槽是否开始做电价套利。
在 0.90 元/kWh_H2 外部价与 el_eff≈0.65 下,谷时制氢成本 0.30/0.65 = 0.46 元/kWh_H2
(低于外部价),峰时 1.00/0.65 = 1.54(高于外部价)—— 外部价第一次落在谷峰成本之间,
套利才有意义。原价 30 元时制氢在任何时段都便宜约 50 倍,不套利是最优的。

- `corr(TOU 电价, 电解槽总功率)` ≤ −0.50 **且** 日内变异系数 ≥ 0.25
  → 「电解槽平剖面是氢价单位错误的产物」成立;
- 相关系数仍 > −0.30 且 CV < 0.12 → 该解释被推翻,平剖面另有原因,须重新归因;
- 落在两者之间 → 不下结论,补 seed 31/32。

**次判据一(终端结算占比):** `|终端结算| / |total_cost|` 从对照臂的约 15 倍降到 < 0.5
→ 「目标函数被终端结算主宰」随单位改正而解除。

**次判据二(内部市场):** h2kg 臂的外部卖出量(`e_h2_ext < 0` 部分)相对对照臂下降 > 50%
→ 「囤积占优导致市场不出清」由价格失真造成。若不降,说明病因在运输途损/ETA 而非价格。

**次判据三(安全):** h2kg 臂按日评估是否仍 28/28(评估带 0.95/1.05)。
预期持平或更好(电解槽负荷下降 → 净购电下降 → 电压裕度上升)。
**若掉出 28/28,是本轮最有价值的结果**:说明此前的 28/28 有一部分是被那个失真的平剖面
「买」来的,安全性结论需要加限定语。

### 禁止的比较(写进结论)

两臂的 `economic_cost` / `reward` **绝对值不可比**——目标函数本身变了(氢价差 33 倍)。
只有无量纲的结构量(相关系数、变异系数、占比、安全日数、电压分位)可以跨臂比较。
任何「新价便宜了多少」的说法都是错的。
