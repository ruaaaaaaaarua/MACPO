# MACPO microgrid paper workspace

This repository contains the local working snapshot for the electricity--hydrogen multi-microgrid MACPO/SGR-MACPO paper:

- `ijepes_sgr_macpo_offline_handoff_20260823_v2/` — English and Chinese LaTeX manuscripts, figures, and local evaluation code.
- `服务器归档_20260826/` — extracted server archive with datasets, code snapshots, checkpoints, diagnostics, and experiment results.
- `算法文章/` — reference papers used during revision.
- `图/` — environment-figure drafts.

The downloaded archive's compressed `.tar.gz` is not committed because it duplicates the extracted `服务器归档_20260826/内容/` tree. The local virtual environment, Python bytecode, and LaTeX build intermediates are also excluded; they can be recreated from the project files. See `服务器归档_20260826/README_归档说明.md` for archive provenance and SHA-256 information.
